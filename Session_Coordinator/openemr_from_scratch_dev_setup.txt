Pre-requisites:
You will need podman installed and a local mysql instance to connect to.
Clone https://github.com/openemr/openemr-devops
Navigate to release version you'd like to use, e.g. /openemr/openemr-devops/docker/openemr/7.0.3
Edit Dockerfile, add a new line "ENV MYSQL_HOST=host.containers.internal" right above CMD [ "./openemr.sh" ]
Build the image:  podman build -f Dockerfile -t openemr-local


1a. If you have previously run openEMR against your local db, clear out the install debris
	> mysql -u root
	> drop database openemr;
	> use mysql;
	> drop user 'openemr'@'localhost';

	> Or, against the RDS instance in wavelength:
	> kubectl run mysql-client --image=mysql:5.7 -it --rm --restart=Never -- /bin/bash
    > mysql -h wlc-openemr-wavelength.cn756c5trc0k.us-east-1.rds.amazonaws.com -u admin -p
    > drop database openemr;
    > drop user 'openemr'@'10.2.1.202';
    > (User's IP will be whatever value is returned as the IP of the openemr pod from kubectl get pods -o wide)

1b. Dockerized sql container - only if not running mysql on local machine
	> podman run -e MARIADB_ROOT_PASSWORD=password mariadb:11.4
	> find IP of sql & openemr container needed for step 3: 'podman network inspect podman' or 'docker network inspect bridge'
		> podman and bridge are default network names, you may need 'docker/podman network inspect' to track down the IPs
	> during install process (step 3)
		> "User Hostname" = ip of openemr container (the ip of what you're connecting FROM)
		> "Server Host" = ip of sql container (the ip of what you're connecting TO)
		> "Root Password" = password
	> if using fresh container for every openemr setup you shouldn't have to do any cleanup from 1
	

2. Start container
	> podman machine init (if needed)
	> podman machine start (if needed)
	> podman run -p 8080:80 openemr-local


3. Go through install process
	> in browser go to localhost:8080/
	> select "Have setup create the database"
	> Server host should be "host.containers.internal"
	> Leave everything else as default, can use "openemr" as password for db user
	> For initial user name, I use "openemr-local-admin". Same value for password.


(site will spin for a while, then finish set up by clicking through next steps)	


4. Turn on REST API and password grant
	> Log in to localhost:8080/ with user created during install
	> At the top, go to Admin > Config
	> Select Connectors
	> Enable checkbox for "Enable OpenEMR Standard REST API"
	> Enable "Enable OAuth2 Password Grant"
	> Click "Save"
